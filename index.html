Find User ID

The user ID can be found through Settings > Support in the top right corner.

(Tap the copy button on the right of the user ID to copy it.)

Cautions

  • 1. If the user ID is entered incorrectly, the item may not be rewarded or it may be rewarded to a different account. In these cases, the coupon cannot be canceled.
  • 2. Coupon rewards are delivered to your mailbox within the game. If you do not see them, exit the game and launch it again. (The mailbox is unlocked after the jar fairy facility is installed.)
  • 3. Coupons that have been registered cannot be sold or traded, and they must be used within the expiry date.
  • 4. If you have any questions regarding coupon use, send an inquiry through Settings > Support > Send Mail.
  • 5. You may be subject to limits if you engage in abusing behavior regarding coupon use or loopholes.

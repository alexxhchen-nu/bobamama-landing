# Bobamama landing — 珍奶铺主城（设计说明）

日期：2026-11-24  
状态：已口头确认，开工中

## 产品

- Bobamama：台语（Taiwanese Hokkien）学习
- 现在：marketing / waitlist landing
- 以后：完整语言学习产品；主城是珍珠奶茶铺

## 世界设定（锁定）

- 舞台：台湾奶奶的珍珠奶茶铺
- 主页隐喻：在铺子里解锁人物、聊天、开放故事线
- 玩法细节（打卡规则、积分、卡牌等）**未定** → landing 只暗示「有进度 / 可解锁」，不写死系统

## 视觉参考

- Craft 参考：`docs/DESIGN-catsnsoup-extract.md`（Cats & Soup redeem）
  - 借：全幅插画世界、rem 游戏 UI 感、温馨低能量、主 CTA 像道具
  - 不借：兑换木牌 / 填券表单当首屏主角
- 字体：Fuzzy Bubbles（display）+ Balsamiq Sans（body），自托管
- 色板方向：暖木色奶茶铺 + 叶绿（可吸收 CNS 草地绿作氛围，不以猫汤品牌为准）

## 页面结构

1. **首屏（一景）**：珍奶铺全幅场景；品牌 Bobamama 英雄级；一句 headline；一句支撑；CTA（候补名单 + 试声调）
2. **在铺子里学**：三步循环 — 进故事章节 → 开口被纠正 → 解锁人物聊新话题（虚化积分/卡牌）
3. **声调纠正**：可交互 tone drill + 简短价值说明
4. **Heritage**：「听得懂，说不出口」
5. **候补名单**：邮箱；原型可不接真 API
6. **页脚**：品牌 + early access 说明
